# ProxyWin 0.5.0

Windows x64 GUI for routing selected IPs or processes through SOCKS5 / HTTP proxies using WinDivert.

## Download

Download **ProxyWin-0.5.0-win-x64.zip**, extract the entire archive, and run **ProxyWin.exe** as administrator. Keep the included runtime and `driver` folder beside the executable. No separate .NET installation is required.

The accompanying `.sha256` file contains the archive checksum.

## Features

- Multiple SOCKS5 / HTTP proxy servers and ordered DIRECT / PROXY / BLOCK rules.
- IPv4 / IPv6, destination IP / CIDR / `*`, port lists / ranges / `*`, TCP / UDP and executable-name conditions.
- SOCKS5 TCP CONNECT and UDP ASSOCIATE; HTTP CONNECT for TCP.
- Live new-connection metadata, process search and rule creation from an observed connection.
- English compact GUI, round `!` help buttons and a Windows application icon.
- Fix for the process-picker caret jumping to the start after typing `w`.
- Windows DPAPI-protected settings, compatible with existing version-2 profiles.

For a process-wide rule, use Destination `*`, Port `*`, Process `chrome.exe`, and select the action and protocol. HTTP/Burp requires TCP; TCP + UDP requires SOCKS5. A blank process field applies to all processes.

## Validation and limits

- Non-elevated regression groups: **16/16 passed**.
- Published GUI and process-caret regression checks passed.
- **Administrator WinDivert tests for 0.5.0 were not run because Windows UAC approval was cancelled.** Wildcard routing through the actual driver remains unverified for this release.
- Loopback/self destinations, IP fragment reassembly and partial IP patterns such as `192.168.*.*` are unsupported. Use CIDR for address ranges.
- Rules use first-match order. PROXY affects new TCP connections. BLOCK silently drops matching outbound packets while rules are active.
